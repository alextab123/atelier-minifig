# Atelier Minifig — Prototype e-commerce

## Ouvrir le site
Double-cliquez sur `index.html`.

## Fonctions incluses
- Page d'accueil premium et responsive
- Catalogue de figurines
- Recherche par nom, référence et univers
- Filtres par univers et état
- Tri par prix et nom
- Fiche produit en fenêtre
- Panier interactif
- Adaptation mobile

## Pour le transformer en véritable boutique
1. Remplacer les SVG d'exemple dans `assets/` par vos photos.
2. Connecter un back-office Shopify, WooCommerce ou Supabase.
3. Connecter Stripe ou Shopify Payments.
4. Ajouter les pages légales, livraison, retours et CGV.
5. Brancher un nom de domaine.
